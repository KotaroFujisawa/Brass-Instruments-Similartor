# トランペットのマウスピース断面を細分化した比較

YorkのB♭管体と等価球面のベル放射を使い、マウスピース周辺だけを変更する。従来形状・従来格子、従来形状・細分格子、実測Bach 5C輪郭・細分格子の順に比較する。線形入力インピーダンスと、唇と管を双方向に連成した吹奏計算の両方を行う。

## 形状と比較条件

従来形状はBach 7Cの開放単体共鳴806 Hzを参考に作成した、全長69.74 mmの近似形状。Bach 5CはJacksonとScavoneが掲載した図2の実測輪郭から、PDFのベクトル曲線111点を抽出した。全長87.13 mm、入口平面の直径20.21 mm、スロート最狭部3.68 mm、出口径8.45 mm。入口平面径は公称カップ径と定義が異なる。カップとスロートを形状保存三次補間で結び、資料の直線バックボアを保持した。論文のライセンスはCC BY-NC 4.0。 [Jackson & Scavone 2025、図2](https://doi.org/10.1121/2.0002165)

5Cの出口は1.8 mmのモデル上の接続区間を介して従来のYorkのリードパイプにつなぐ。元のYork管体は同じ断面と長さを使う。接続後の音響差には、5Cのカップ、スロート、バックボア、全長、およびこの接続区間の変更が一緒に入る。

細分条件では局所の軸方向格子間隔を従来の0.60倍にし、5Cのリム近傍の一部を最大0.30 mm間隔とした。開放運指で、従来形状・細分格子はマウスピース内54列、5Cは68列。リムとカップの入口平面に対応する面積を、唇境界の流量計算にも使う。吹奏圧、アタック、唇の固有振動数・減衰、運指、管長補正は同じプリセットで比較する。

## 計算

線形診断は円筒の伝達行列を用い、Bessel関数による熱と粘性の応答を加える。マウスピース単体は出口開放（非フランジ円管放射負荷）と出口閉鎖の条件を区別する。管体装着時の線形計算は、等価球面放射の断面平均モードをベル負荷として使う。

弱いパルスと演奏音は、軸対称圧縮性Euler方程式と多モードのベル放射で求める。吹奏例は実音B♭4とB♭6で、正面1 mの音を共通ゲインでWAVにする。マウスピースの交換は発振時の戻り波と口元の圧力を変えるため、入力インピーダンスのピークと放射音の基音を別々に記録する。

単体の開放第1共鳴は線形計算で818.23、810.14、704.60 Hzだった。接続後の吹奏音は、B♭4が465.67、464.95、462.34 Hz、B♭6が1867.75、1868.84、1870.05 Hzだった。5C単体の出口閉鎖時、軸対称計算で得た最初の3ピークは1118.08、3339.21、5574.55 Hz、文献実測は1216.9、3426.5、5607.1 Hzだった。実測との比較には、入口の加振分布や測定器との接続形状も関与する。

## 再生成

```sh
python src/compare_trumpet_mouthpiece.py
python src/render_trumpet_mouthpiece.py --impedance
python src/verify_trumpet_mouthpiece.py
python src/render_trumpet_mouthpiece.py
```

音源、入力インピーダンス、形状と共鳴の比較図、出力音の測定値は `output/trumpet_mouthpiece/` に出る。吹奏計算とパルス計算にはCUDAが必要。

## Bach 5Cでの3オクターブ音階

```sh
python src/render_trumpet_bach5c.py
```

実音B♭3からB♭6までのB♭メジャー22音。各音1.08秒、最後のB♭6は1.65秒、音間と末尾の無音は0.09秒で、合計26.31秒。音源と各音の測定は `output/trumpet_bach5c/` に出る。

Bach 5Cの輪郭、York管の細分化したテーパー、4つのベル開口モードに結合した等価球面放射を使用する。放射音は正面1 mの圧力から求める。口元の局所格子は主に0.60 mm間隔、C4・D4では0.30 mm間隔を用いる。通常は吹奏圧を10〜14 msで立ち上げて一時的に22%加える。E♭4では9 ms、28%を用いる。一部の音は唇の固有振動数、吹奏圧、有効管長を調整した。各音の設定差は `data/performance_trumpet_bach5c.json` を参照。
