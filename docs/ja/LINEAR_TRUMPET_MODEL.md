# トランペット物理シミュレーション

同じ軸対称ソルバーで計算したConn 8Hテナートロンボーンは [TROMBONE_MODEL.md](TROMBONE_MODEL.md) を参照してください。
半径方向も解く軸対称Eulerモデルと唇の連成は [AXISYMMETRIC_MODEL.md](AXISYMMETRIC_MODEL.md) を参照してください。
非線形な戻り波を唇へ返す双方向連成の第3版は [BIDIRECTIONAL_MODEL.md](BIDIRECTIONAL_MODEL.md) を参照してください。
非線形伝搬を追加した第2版は [NONLINEAR_MODEL.md](NONLINEAR_MODEL.md) を参照してください。
このREADMEの以下の説明は、比較の基礎となる第1版の線形管体モデルについてです。

実音 **B♭3〜B♭5のB♭メジャー上行15音**を、フォルテを想定した吹奏条件で合成します。
48 kHz・16 bit・モノラル、約12秒。各音0.72秒、最後のB♭5は1.1秒です。
ピッチシフト、録音サンプル、加算合成、リバーブは使用していません。
配布用ZIPには音声・ソース・設定・検証図／JSONを収録しています。全音の時系列とPa単位の解析用WAVは、再生成時に出力されます。

## ファイル

- `output/trumpet_Bb3_Bb5_major_f.wav`：試聴用音声。
- `src/trumpet.py`：唇・流量・管体・マウスピース・放射のモデル。
- `src/render_scale.py`：バルブ、各音の演奏条件、音声の生成。
- `src/verify.py`：物理・数値検証と診断図の生成。
- `data/performance.json`：最終版の15音の吹奏圧、唇固有振動数、静止位置。
- `data/york_trumpet_fig7_52.csv`：教科書の図から読み取った管体形状。距離と直径、単位m。
- `data/model.json`：マウスピースの校正値。
- `data/sources.json`：出典・ページ・数値の根拠・推定した寸法の区別。
- `output/measurements.json`、`output/verification.json`：実際に測定した周波数と検証結果。
- `output/diagnostics.png`：形状、入力インピーダンス、波形、音程誤差、唇の軌道、スペクトル。
- `output/trace_*.npz`：解析用の時系列。列はマウスピース圧力p、総流量U、唇x、唇y、通過流量Ua、唇の排除体積流量Ul、吹奏圧pm、唇隙間圧plip。
- `output/trumpet_Bb3_Bb5_radiation_Pa_float.wav`：解析用の放射圧力。浮動小数点の値はPaであり、試聴用の振幅正規化はしていません。

## 実行

Python 3.12で動作を確認しました。通常のPython環境では以下を実行します。

```sh
python -m pip install -r requirements.txt
python src/render_scale.py --render
python src/verify.py
```

最終演奏条件を保存しているため、再生成に探索は必要ありません。
`tmp`内の応答キャッシュがなければ、形状から自動計算します。
新しい演奏条件を探す際は `python src/render_scale.py --fit` を使用できますが、これは粗い初期探索です。
発振モードの飛びや持続中の遷移があるため、最終プリセットを上書きする前に複製してください。
`python src/trumpet.py --probe` はマウスピース校正と発振条件の試験を行います。
この作業環境の依存ライブラリは `.deps` に置いてあります。別の環境ではpipでのインストールで足ります。
`BRASS_DEPS` は任意のローカル依存ライブラリの場所を指定するための環境変数です。

## 唇：Adachi–Sato (1996)

Adachi and Sato, *Trumpet sound simulation using a two-dimensional lip vibration model*, JASA 99, 1200–1209, DOI: 10.1121/1.414601。
添付PDFの4〜6ページ、原論文pp.1202–1204の式(1)〜(10)を基にしています。

上唇先端を `xi=(x,y)`、支点を `joint=(0,4 mm)` として、

```text
(m/2) xi'' + (sqrt(m*k)/(2*Q)) xi' + (k/2)(xi-xi_eq)
    = b(pm-p) perpendicular(xi-joint) + b*d*plip*ey + Fcontact

S = max(2*b*y, 0)
Ul = b * [x*y' - (y-joint_y)*x']
U = Ua + Ul

pm-plip = rho/2 * (Ua/S)^2 + rho*d/S * dUa/dt
plip-p  = -rho*Ua^2 * [1/(Scup*S) - 1/Scup^2]
```

幅b=7 mm、厚さd=2 mm、静止x=1 mm、開口時Q=3、閉鎖時Q=0.5。
質量 `m=1.5/((2*pi)^2*f_lip)`、剛性 `k=1.5*f_lip` は原論文Table Iに従います。
接触時は追加復元力 `-3*k*y` を加えます。
二方向の変位、接触、唇の排除体積流、隙間の流体慣性を実装しており、単なる1自由度のリードモデルではありません。

空気流が一時的に逆転する場合には、二乗の流れ抵抗を `Ua*abs(Ua)` とする符号付きの拡張を行っています。
原論文では唇固有振動数60〜700 Hz、吹奏圧2〜5 kPaが検討されています。
今回の高音・強奏ではこの範囲を拡張しています。唇の静止yも演奏条件として調整しています。
Table Iの静止yの単位は印刷上 `10^-3 cm` です。今回の調整値は原表の範囲を厳密に維持したものではありません。

## 管体とマウスピース：The Science of Brass Instruments

Campbell, Gilbert and Myers, *The Science of Brass Instruments* (2021)を主資料としました。

管体は図7.52（本文p.373、添付PDF p.385）の**York製B♭トランペット、1925–27年、EU(5772)**の赤い曲線を数値化しました。
図の原画像は591×406画素で、1画素は軸方向約2.8 mm、直径方向約0.43 mmです。
軸との重なりやベル先端などでは誤差が増えます。これは製造図や元の実測表ではなく、掲載図からの近似です。
口元からではなくマウスパイプ入口からの曲線なので、マウスピースは別途付加しています。

マウスピースはカップ、直径3.7 mm・長さ6 mmのスロート、55 mmの円錐バックボアを持つ分布定数モデルです。
3.7 mmは同書§1.2.8にある代表的なトランペットの値、入口面積230 mm²はAdachi–Satoの値です。
カップは丸みを持つ収束形状とし、深さを約8.735 mmにすると、単独マウスピースの共鳴が806 Hzになります。
806 Hzは図4.40（本文p.147、添付PDF p.160）のBach 7Cのデータです。
スロートの長さ、バックボアの寸法、カップの形状は補った仮定です。
**Bach 7Cの形状を完全再現したものではありません。共鳴周波数1点だけから形状は一意に決まりません。**

約2 mmの円筒要素による伝達行列を用い、同書§4.7の式(4.108)〜(4.112)に基づく粘性・熱損失と分散を入れています。
平方根周波数に比例する損失・位相補正は因果的な先頭項を使用しています。
放射終端は式(4.121)の低周波抵抗 `(ka)^2/4` と長さ補正 `0.61*a` に一致する、受動的なRL近似です。
形状から計算した入力インピーダンスを反射応答へ変換し、原論文§I.Bの因果化を施して唇と結合します。
カップが急に狭まる部分もこのフィードバック系に含まれます。

*Acoustics of Musical Instruments* §7.3.4、pp.312–317も参照し、バックボアの空気体積を無視する単純なカップだけのヘルムホルツ共鳴器に置き換えていません。
添付の *The Physics of Musical Instruments* は関連説明を確認しましたが、本実装の数値寸法を同書から採用してはいません。

## 音階と強弱

実音：B♭3 C4 D4 E♭4 F4 G4 A4 B♭4 C5 D5 E♭5 F5 G5 A5 B♭5。
基準はA4=440 Hz。B♭管の記譜ではC4からC6です。
各音で標準的な運指を選び、バルブによる管長追加を円筒部分に組み込みます。
1・2・3番バルブはそれぞれ全音・半音・短3度の公称長を加算します。形状全体のピッチ変換は行いません。
バルブを動かしている途中の流路変化は計算せず、各発音の間で管体を切り替えます。

フォルテは単一の普遍的な圧力値ではありません。今回は音域ごとに約5.4〜13 kPaの圧力を選び、持続振動が得られる唇の設定を使用しています。
再生ファイル全体には共通のゲインを1回だけ適用し、音ごとの個別正規化はしていません。
実際の再生音量は再生機器に依存します。

## 数値計算と検証範囲

96 kHzで結合系を積分し、アンチエイリアスフィルタ付きで48 kHzへ変換します。
唇は減衰を含む中心差分、流体慣性は後退差分とし、反射応答の同時刻成分を含む流量の二次方程式を各ステップで解きます。
波形や変位をクリップして発散を隠す処理はありません。
ベルの体積流量は同じ伝達行列から求め、自由空間・距離1 mのコンパクトな単極子近似で放射圧力へ変換しています。

検証は、実際の出力の音程・持続周期性・クリッピング、反射率の受動性、流量方程式の残差、96/192 kHzでの時間刻み比較、1/2 mmでの管体分割比較を行います。
最終的な値は `output/verification.json` を参照してください。
今回の出力では最大音程誤差3.16セント、クリッピング0サンプルでした。
計算レートを96 kHzから192 kHzへ変えた際の音程差は、B♭3で0.09、B♭4で0.38、B♭5で1.06セントでした。

**近似の限界：** 管内伝搬は線形1次元モデルで、強奏時の衝撃波形成を含む非線形伝搬、3次元ベル放射、管壁振動、声道、乱流息音、室内残響は未実装です。
特に強い金管らしい鋭さの再現には、教科書第6章の非線形伝搬を追加する余地があります。
また、資料の異なる楽器・代表的マウスピースのデータを組み合わせた再構成であり、特定の現物の録音を忠実に再現したという主張ではありません。
