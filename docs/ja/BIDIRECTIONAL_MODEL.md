# 非線形な戻り波と唇を連成した第3版

実音B♭3〜B♭5のB♭メジャー上行15音を、フォルテの吹奏条件で生成します。
48 kHz・16 bit・モノラル、12.08秒です。

この版では、マウスピースからベルへ進む波と、ベル・管径変化から戻る波を、両方とも時間領域で伝搬させます。
**非線形に変形して入口へ到達した戻り波を、各時刻の唇と流量の境界条件に直接使用します。**
その結果として変化した唇の運動が次の進行波を作る、閉じた自励振動系です。
第2版の音声を入力して後処理する構成ではありません。

## 出力と再生成

- `output/bidirectional/trumpet_Bb3_Bb5_major_f_bidirectional_nonlinear.wav`：主音声。
- `output/bidirectional/trumpet_Bb3_Bb5_major_f_bidirectional_linear_reference.wav`：同じ吹奏条件で管内の非線形係数だけを0にした比較音。
- `output/bidirectional/comparison_bidirectional_linear_then_nonlinear.wav`：線形版、0.5秒の間、非線形版の順。
- `output/bidirectional/measurements.json`：各音の周波数、スペクトル、戻り圧力、唇の変位。
- `output/bidirectional/solver_tests.json`、`verification.json`：実際に実行した検証結果。
- `output/bidirectional/diagnostics.png`：波形・唇の軌道・スペクトル・音程の比較図。
- `data/performance_bidirectional.json`：最終的な演奏条件。

```sh
python -m pip install -r requirements.txt
python src/render_bidirectional.py
python src/verify_bidirectional.py
python src/verify_bidirectional.py --full
python src/plot_bidirectional.py
```

音程は、唇の剛性・質量・静止開口を調整して合わせています。ピッチシフトは使用していません。
各音で管体とバルブを切り替え、静止状態から発音します。バルブを押す途中の流路切替は計算しません。
吹奏圧は約5.4〜13 kPaです。「f」を一意の圧力に対応させた測定値ではなく、強奏を想定した演奏条件です。
原論文で検討した吹奏圧・唇固有振動数の範囲を、高音・強奏側へ拡張しています。

## 出典と形状

主資料は Campbell, Gilbert and Myers, *The Science of Brass Instruments* (2021)です。
§6.2.2–6.2.3、本文pp.291–295（添付PDF pp.304–308）の弱非線形伝搬・損失を基にしています。
同書のWebster方程式と断面変化の反射を、円筒区間の進行波ネットワークで表現しました。
時間領域での非線形伝搬・因果的損失・唇のフィードバックの組合せについては、同書が引用する
[Berjamin et al., “Time-domain numerical modeling of brass instruments including nonlinear wave propagation, viscothermal losses, and lips vibration”](https://arxiv.org/abs/1511.04247)
も参照しました。同論文のコードや方程式系をそのまま再現したものではありません。

管体は図7.52のYork製B♭トランペットの曲線を数値化した前版と同じものです。
カップ、スロート、バックボアも含め、全域を双方向伝搬領域とします。
マウスピース寸法の根拠と推定の区別は `README.md` と `data/sources.json` に記載しています。
図4.40の単独マウスピース共鳴806 Hzは前版の校正値であり、今回の離散伝搬系で改めて806 Hzに強制してはいません。
掲載図からの近似形状であり、特定の現物の正確な製造寸法ではありません。

唇は Adachi & Sato (1996), JASA 99, 1200–1209, DOI 10.1121/1.414601 の2次元モデルを引き継ぎます。
二方向の変位、接触、唇の排除体積流、隙間の流体慣性を含みます。
空気流が逆転する場合の抵抗を `Ua*abs(Ua)` とする拡張も前版と同じです。

## 双方向の計算

各断面で、圧力波を `p+`、`p-`、断面積を `S`、`Z=rho*c/S` とします。

```text
p = p+ + p-
U = (p+ - p-)/Z
```

隣接断面の接続部では、圧力と体積流量の連続条件から

```text
r = (S_left - S_right)/(S_left + S_right)
p+_right,new = (1+r)*p+_left - r*p-_right
p-_left,new  = r*p+_left + (1-r)*p-_right
```

を計算します。ベルだけでなく、カップの絞り、バックボア、マウスパイプ、ベル途中の反射も毎時刻計算されます。
ベル終端は低周波の放射抵抗 `(ka)^2/4` と端補正 `0.61*a` に一致する受動的RL近似です。
Tustin法で時間領域に変換し、その時刻の反射波を管内に戻します。

唇側では、実際に届いた `p-` を使って

```text
p_mouthpiece = Z0*(Ua + Ul) + 2*p-_arriving
p+_launched  = Z0*(Ua + Ul) + p-_arriving
```

とします。`Ua` は隙間を通る流量、`Ul` は唇の排除体積流です。
第1式を隙間の流れの方程式へ代入し、流体慣性を含む二次方程式を各ステップで解きます。
音圧が唇の運動方程式の力に入り、次の時刻の開口と排除体積流を変えます。
固定の反射インパルス応答に置き換えることはしていません。

## 非線形伝搬と損失

空気は `rho=1.2 kg/m³`、`c=343 m/s`、`gamma=1.4`、`beta=(gamma+1)/2=1.2` とします。
線形伝搬・断面散乱と、振幅依存の速度補正を演算子分割します。
管半径 `a(x)` による変数 `q±=a*p±_ac` に対し、補正項は

```text
dq±/dt = ∓ beta/(rho*c*a) * d[(q±)^2/2]/dx
```

です。左右の符号を反転させるため、どちら向きに進む圧縮波も、その進行方向に速くなります。
非線形項はMUSCL-MC再構成、局所Lax–Friedrichs流束、SSP-RK2で積分します。
境界で発生した反射波も次の伝搬ステップから同じ非線形計算を受けます。

壁面損失・分散は平方根周波数に比例する先頭項を採用します。
`sqrt(s)` を正の重みを持つ8項の `s/(s+theta)` の和で近似し、各区間・各方向に因果的な状態変数を持たせます。
40 Hz〜25 kHzでの連続時間の近似誤差の最大値は約1.02%です。
各区間の伝達特性は `1/(1+K*sqrt(s))` の近似であり、受動的です。
特性インピーダンスは実数 `rho*c/S` としており、前版の複素特性インピーダンスの高次補正まで一致するわけではありません。

体積損失は `delta/2 * d²q/dx²` を用います。
`delta=[4*eta/3 + kappa*(gamma-1)/Cp]/rho` とし、空気の代表値は第2版と共通です。
分子緩和・体積粘性は含みません。
20 Hzの因果的な平均値推定で平均吹奏流と音響波を分け、非線形の波形変形は音響成分に適用します。
平均流による移流を精密に解く流体モデルではありません。

## 計算精度と限界

結合系全体を192 kHzで計算し、`dx=c/fs`（約1.79 mm）の区間を用います。
開放管では759区間です。最後にアンチエイリアスフィルタを通して48 kHzへ変換します。
非線形補正自体は2段法ですが、全体の演算子分割を2次精度と主張してはいません。
衝撃波の鋭さには数値散逸も影響するため、384 kHzとの比較を別途行っています。

これは**双方向の弱非線形音響モデルと唇の閉ループ連成**です。
対向波同士の高次の非線形混合を含む完全な圧縮性Navier–Stokes解ではありません。
管壁振動、声道、乱流音、室内残響、ベル外の非線形伝搬は含みません。
放射音は実際のベル体積流量から距離1 mの単極子近似で計算しており、ベルの高域指向性は近似です。
すべての音と線形比較版に共通のゲインを1回だけ適用します。

旧版との違いには、伝搬法・損失の離散化・唇の再調整も含まれます。
非線形項の効果を比較する際は、この版に同梱した線形比較音を使用してください。
線形比較音でも唇と流れは非線形で、管内の `beta` だけが0です。
非線形係数の変更で音高や周期性も変わります。今回の線形比較版の低音側には周期変動があるため、単純な音色だけの差ではありません。

## 検証内容

1. 円筒内の正弦波が非線形伝搬したときの第1〜第4倍音を、衝撃波形成前のFubini解析解と比較。
2. 反射パルスが管を往復してから入口に届くことを確認。
3. 非線形項を0にした時間領域の反射特性を、同じ離散モデルの伝達行列と比較。
4. 全音の `p-Z0*U-2*p-` と流量方程式の残差、有限値、音程、周期性、クリッピングを検査。
5. G4、B♭4、B♭5を同じ吹奏条件で384 kHzでも計算し、音程と音圧を比較。
6. 非線形オン／オフの戻り波と唇の変位を比較。戻り波を唇に渡さない診断計算も実施。

今回の結果では、放射音の主音高の最大誤差は4.11セント、クリッピングは0サンプルでした。
192/384 kHzの比較で、マウスピース圧力の周期から得た周波数差は3音とも0.45セント以内、
放射音RMSの差は0.13 dB以内、3 kHz以上のエネルギー比率の差は0.88 dB以内でした。
入口の圧力・流量境界条件の残差は最大約3.64e-12 Pa、流量方程式の残差は最大約2.83e-7 Paでした。
B♭4では、戻り波を唇側の式から外す診断計算で持続発振が消え、実際にフィードバックで発振していることを確認しました。

G4には弱い周期倍化が残ります。放射音の約196 Hz成分は、主成分の約392 Hzより約32 dB低い値です。
この成分を消すフィルタは掛けていません。検証JSONのG4の管内周期周波数が約196 Hz、放射音の主音高が約392 Hzとなるのはこのためです。
厳密に単一周期の15音を作るための演奏条件の完全探索までは行っていません。

解析用の `*_coupled.npz` には非線形版と線形版の全レートの時系列を保存します。
列は、入口音圧、総流量、唇x、唇y、通過流量、唇の排除体積流、吹奏圧、隙間圧、
入口へ戻った圧力波、入口から出る圧力波、ベル体積流量、ベル音圧の順です。
大きな時系列ファイルは配布ZIPから省き、再生成で取得できるようにしています。
