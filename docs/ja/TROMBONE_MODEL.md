# Conn 8Hテナートロンボーンの軸対称シミュレーション

実音B♭2〜B♭4のB♭メジャー上行15音を、フォルテを想定した吹奏条件で生成します。テナートロンボーンに合わせ、トランペット版より1オクターブ下を選びました。各音は0.72秒、最後のB♭4は1.10秒です。WAVは12.08秒、48 kHz、16 bit、モノラルです。

## 管体とスライド

Campbell, Gilbert and Myers, *The Science of Brass Instruments* (2021) の図4.22と本文p.128（添付PDF p.141）の、Conn 8HとDenis Wick 5ALの組合せを使いました。本文の接続位置0.256、0.761、0.951、1.694、2.269、2.764 mを採用しました。ベルの半径変化は図の青い実線から読み取り、円筒部半径は公称ボア径0.547インチから6.947 mmとしました。図の横軸と本文の末端位置には約70 mmの差があるため、フレアの軸方向座標は本文の節点に合わせて換算しました。ベル出口半径は図から106.5 mmとしています。スライド両端の細部は画像の解像度に応じた近似です。元にした画像で半径方向の1画素は約0.39 mmです。[Conn 8Hの公称ボア](https://connselmer.com/instruments/trombones/conn-symphony-tenor-trombone-in-bb-8h)

スライドの片道移動量は、B♭1の有効管長を基に `c/(4*f_Bb1) * (2^((position-1)/12)-1)` で求めます。U字の両脚に延長が加わるため、管路にはその2倍を足します。伸縮は内管の端の間にある外管部分に配置します。円筒直管の一部には、チューニングスライドと各音の微調整を表す `trim_m` を加えています。これらの値は、音階のために計算モデル上で合わせた管路長補正であり、実機のスライド目盛りの測定値ではありません。各音で静止した管体を計算します。U字部は中心線に沿って展開し、曲がりによる非軸対称な流れを平均化しています。

## カップ、スロート、バックボア

図4.32b（本文p.139、PDF p.152）のカップ曲線を読み取り、5ALの公称カップ径25.75 mm、スロート径7.3 mmと組み合わせました。本文pp.143〜144（PDF pp.156〜157）の全長80 mm、出口半径6.9 mm、容積12 mLと単体入力インピーダンスの共鳴535 Hzを拘束にして、カップ深さとバックボアのテーパーを校正しました。約37.26 mmのカップ深さと指数3.665のバックボアがこの近似では得られました。535 Hzは線形伝達行列での校正目標です。二次元計算で得た共鳴は検証結果に別記します。[Denis Wick 5ALの公称寸法](https://www.deniswick.com/trombone)

## 非線形の管内伝搬と唇

共有のCUDAソルバーが、密度・軸方向運動量・半径方向運動量・全エネルギーを、軸対称の圧縮性Euler方程式で更新します。円環セルの有限体積法、MUSCL-MC、HLLC流束、SSP-RK2を使用し、許容できない中間状態ではHLLE流束へ切り替えます。管壁損失は因果的な緩和で近似します。式と離散化は `AXISYMMETRIC_MODEL.md` に示します。

入口では、実際に戻った音響特性量 `p-p0-rho0*c0*u` の断面平均を求め、Adachi–Satoの二自由度唇モデルに結合します。唇の前後・上下運動、閉鎖接触、隙間を通る流れの慣性、唇が押しのける流れを含みます。小マッハ数の特性境界を使います。トロンボーンの唇の有効寸法・質量・減衰は推定し、音ごとに固有振動数、静止開口、吹奏圧を調整しました。教科書図3.14に示されるトロンボーンの唇の二方向運動と、§2.1.3のF4のフォルテでの口内圧3.7 kPaを参考にしています。実測される閾値や音量は奏者・音域・装置によって変わります。[Adachi–Sato](https://doi.org/10.1121/1.414601)

ベルでは平均モードの低周波放射インピーダンスを使い、外部音はベル体積流量の時間微分に基づく単極子近似です。音声に共通ゲインを使い、各音の周波数は数値モデルから自励発振した結果です。衝撃波を捕獲する機能は衝撃波管で検証します。演奏音のすべての圧縮波が衝撃波になると仮定するモデルではありません。

## 再生成と検証

CUDA対応のNVIDIA GPUと、現在のドライバと互換性のあるNVRTCが必要です。この環境では12.4.127を使用しました。

```sh
python -m pip install -r requirements.txt
python -m pip install nvidia-cuda-nvrtc-cu12==12.4.127
python src/verify_trombone.py
python src/trombone_axisymmetric.py
python src/verify_trombone.py --coupling
python src/plot_trombone.py
```

実行結果は `output/trombone_axisymmetric/` に保存されます。`geometry_verification.json` は容積、単体の共鳴、スライド第1・第7ポジションの長さ、図4.46と比較する第1ポジションの共鳴周波数を記録します。`solver_tests.json` は保存性、Sod衝撃波管、円筒の半径方向モードの検証です。`coupling_tests.json` はB♭3の戻り波を唇へ返す場合と外した場合、格子を細かくした場合の比較です。音高などの演奏結果は `measurements.json` にあります。

今回の軸対称計算では単体マウスピースの共鳴は519.6 Hz、完成管第1ポジションの初めの6つのピークは37.9、109.3、167.0、232.3、292.9、347.2 Hzでした。図4.46からの読み取り値との差はおおむね5 Hz以内です。B♭3では唇への戻り波を外す診断で持続発振が消え、格子を細かくした診断での音高の変化は約0.21セントでした。衝撃波管では200セルから400セルに増やすと圧力の平均誤差がほぼ半減しました。

流体の時間刻みは約1.30 µsです。RTX 2000 Ada Generationで、GPUを単独で使って0.72秒の1音を約7.5秒で積分しました。

強いアタック版では、吹奏圧の立ち上がりを標準の35 msから短縮し、一時的に圧力を上げます。余分な圧力は余弦曲線で減衰し、各音の元の持続圧に戻ります。`python src/render_trombone_attack.py --preset data/performance_trombone_attack.json` で、選定済みの設定から `output/trombone_attack/` に再生成できます。音の立ち上がりを比較するため、標準版のレンダリング結果と時系列を参照します。
