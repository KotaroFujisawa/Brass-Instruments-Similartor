# 管内の非線形伝搬を加えた第2版

実音B♭3〜B♭5のB♭メジャー上行15音、12.08秒、48 kHz・16 bit・モノラルです。
唇、マウスピース、管体形状、運指、吹奏圧、各音の長さは第1版の設定を使用します。

## 何を追加したか

『The Science of Brass Instruments』§6.2.2–6.2.3、本文pp.291–295（添付PDF pp.304–308）の一般化Burgers方程式を実装しました。
式(6.33)–(6.34)の振幅に依存する伝搬と管径変化に、式(6.30)の壁面損失・体積損失を加えています。
高い音圧の部分が速く進むため波形が急峻になり、高い倍音が生まれます。
歪みエフェクトやクリッピングをベルの音声に掛ける処理ではなく、管内の距離に沿って進行波を数値積分しています。

この版は**入口の進行波を与える一方向伝搬の近似**です。
同書p.284（PDF p.297）にも、入口波形を指定する伝搬計算と、唇まで連成する計算の区別が説明されています。
既存の線形管体とAdachi–Satoの2次元唇モデルで自励振動を求め、マウスパイプ入口の前進波を取り出して非線形伝搬計算に入力します。
非線形に変形した戻り波が唇・マウスピースの振動や発振音高を変える効果は扱っていません。
完全な双方向の非線形連成モデルを実装したものではありません。

## 方程式

遅延時間を `tau=t-x/c`、管径を `D(x)`、音圧を `p(x,tau)` とします。
空気の比熱比 `gamma=1.4` により、非線形係数は `beta=(gamma+1)/2=1.2` です。

```text
dp/dx - beta/(rho*c^3) * p * dp/dtau + p/D * dD/dx
    = 壁面損失 + 体積損失
```

`q=p*D(x)/D(0)` と置くと、管の広がりによる振幅減衰を厳密に分離できます。

```text
dq/dx + d/dtau[-k(x)*q^2/2] = 損失
k(x) = beta/(rho*c^3) * D(0)/D(x)
```

同書の式(6.35)–(6.37)には正規化径に関する表記の曖昧さがあるため、この実装は式(6.34)から直接変数変換しています。
管径は前版と同じ、図7.52から数値化したYork製B♭トランペットの形状です。
バルブの追加管、ほぼ円筒の部分、広がるベルを含み、マウスピース出口付近からベルまで積分します。
カップ・スロート・バックボアは従来の線形音響モデルに含まれ、今回はその内部を非線形伝搬領域としていません。

壁面損失と分散は第4章の近似と一致させ、周波数領域で

```text
alpha_wall(f,x) = (1+i) * 2*pi*1.045/(c*632.8*a(x)) * sqrt(f)
alpha_bulk(f)   = delta * (2*pi*f)^2/(2*c^3)
```

を用います。振幅減衰だけでなく壁面損失に対応する位相変化も含みます。
体積損失の音響拡散係数は

```text
delta = [4*eta/3 + zeta + thermal_conductivity*(gamma-1)/Cp] / rho
```

です。`rho=1.2 kg/m³`、`c=343 m/s`、`eta=1.846e-5 Pa s` を使用します。
熱伝導率0.0262 W/(m K)、定圧比熱1005 J/(kg K)は代表値を補った仮定です。
体積粘性zetaは0とし、分子緩和の寄与はモデル化していません。

## 入力波形と出力

マウスピース内の定在波音圧を、そのまま進行波として用いることはしていません。
同じ伝達行列モデルからマウスパイプ入口の圧力と体積流量を求め、`p+=(p+Zc*U)/2` に分離します。
平均吹奏流を音響成分から分けるため、入力には30 Hzの2次Butterworth高域通過特性を用います。
これは最低音B♭3の振幅にはほぼ影響しません。線形比較版にも全く同じ特性を適用します。

ベル終端では前版と同じ受動的な放射インピーダンスを適用し、反射を含む終端体積流量から距離1 mの単極子近似で放射音を求めます。
終端から生じる戻り波の再伝搬は行いません。
各音の個別正規化は行わず、音階全体と線形比較版に共通のゲインを使用します。

## 数値計算

- 唇・線形共鳴系：96 kHz。
- 非線形伝搬：192 kHz、距離方向の基本刻みは約10 mm。
- 非線形項：MUSCL-MC再構成、局所Lax–Friedrichs流束、SSP-RK2、CFL条件による自動分割。
- 損失項：周波数領域で積分し、Strang分割で非線形項と組み合わせます。
- 出力：アンチエイリアスフィルタを通して48 kHzに変換します。

衝撃波の立ち上がりには、物理的な損失に加えて衝撃波捕獲法の数値散逸が作用します。
微視的な衝撃波厚さまで分解したという意味ではありません。
音声帯域の倍音が計算刻みを細かくしても大きく変わらないことを別途検証します。

## 検証

`src/verify_nonlinear.py` は以下を確認します。

1. 式(6.27)–(6.28)のFubini解析解と、衝撃波形成前の第1〜第6倍音の一致。
2. 衝撃波形成後のエネルギー減衰、平均値の保存、メッシュ細分化。
3. 損失なし・非線形性なしでの `1/D` の振幅減衰と伝搬時間。
4. 小振幅で線形解に近づくこと。
5. B♭4と、倍音増加が最も大きいG4について384 kHz・約5 mm刻みとの比較。
6. 全15音の放射音の音程、周期性、クリッピング。

実測の検証結果は `output/nonlinear/verification.json`、各音のスペクトル変化は `measurements.json` に保存します。
今回の全15音では最大音程誤差3.17セント、クリッピング0サンプルでした。
B♭4の3 kHz以上のエネルギー比率は線形比較版に対して12.67 dB増加しました。
これは音全体の音量増加ではなく、全音響エネルギーに占める高域成分の比率の変化です。

## 比較音の意味と限界

`trumpet_Bb3_Bb5_major_f_nonlinear.wav` が今回の主音声です。
`trumpet_Bb3_Bb5_major_f_linear_reference.wav` は、同じ入力、管径、損失、放射処理でbetaだけを0にした比較版です。
`comparison_linear_then_nonlinear.wav` は線形版、0.5秒の間、非線形版の順です。

旧版は管体全体の反射・ベルの分散を線形伝達行列で計算していました。
一方向Burgers近似は同書p.295が説明する通り、ベル途中の反射と分散を完全には再現しません。
したがって、**旧版と今回の差には伝搬近似の変更も含まれます**。
非線形性だけの効果を比べるには、今回同梱する線形比較版を使ってください。

前版の形状読取り誤差や推定マウスピース寸法は引き継いでいます。
管壁振動、声道、乱流音、室内残響、ベル外の非線形伝搬は含めていません。

## 再生成

```sh
python -m pip install -r requirements.txt
python src/render_nonlinear.py
python src/verify_nonlinear.py --full
python src/plot_nonlinear.py
```

最終演奏条件は `data/performance.json` を使用します。新たな音程探索は必要ありません。
第1版の実装と音声はそのまま残しています。
