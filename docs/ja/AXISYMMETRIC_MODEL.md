# 軸対称Euler方程式と唇の連成によるトランペット

実音B♭3からB♭5のB♭メジャー上行15音をフォルテの吹奏条件で計算します。WAVは約12秒、48 kHz、16 bit、モノラルです。管の形状には *The Science of Brass Instruments* 図7.52のYork製トランペットの読み取り値を使い、カップ、スロート、バックボアを含めています。形状の出典とマウスピースに置いた仮定は `data/sources.json` に記載しています。軸対称化では曲がった管の中心線に沿った距離を `z` とし、各断面を半径 `R(z)` の円として並べます。

## 流体の方程式

`r` は半径、`u`、`v` はそれぞれ軸方向、半径方向の流速です。密度 `rho`、二方向の運動量、体積あたりの全エネルギー `E` を保存変数にします。

```text
U   = (rho, rho*u, rho*v, E)
F_z = (rho*u, rho*u*u+p, rho*u*v, (E+p)*u)
F_r = (rho*v, rho*v*u, rho*v*v+p, (E+p)*v)
p   = (gamma-1) * [E-rho*(u*u+v*v)/2]

d(r*U)/dt + d(r*F_z)/dz + d(r*F_r)/dr = (0, 0, p, 0)
```

`gamma=1.4`、静止密度1.2 kg/m³、静止音速343 m/sの理想気体です。この保存形では圧縮波と膨張波、進行波と反射波が同じ状態変数を通じて相互作用します。衝撃波をまたぐフラックスは保存変数から計算します。強振幅の圧縮波は弱振幅より速く進み、波面が急峻になります。

断面内は同心円の有限体積に分け、管径変化に合わせて円錐台の体積と面積を計算します。半径方向には断面当たり2〜16セルを使い、隣り合う断面で分割が変わるところでは、軸方向の面を細かい方に合わせて分けます。面を挟む左右の体積に同じ数値流束を使います。`r=0` の面積はゼロです。半径方向の幾何学ソースと圧力流束は、空気が静止して等圧なら相殺します。壁は反射する滑り壁です。

空間離散にはMUSCLとMC制限関数、HLLCリーマン流束を用います。中間状態が許容範囲から外れる場合はHLLEに切り替えます。面再構成で密度・圧力が許容範囲から外れる場合はセルの値に戻し、状態が非物理的になるか波速が時間刻みの想定を超えた場合は計算を停止します。管径が急に変わる軸方向の面では、各リングの軸方向運動量を局所断面積で重み付けして再構成します。これにより滑らかな流量の変化を、面をまたぐ速度の不連続として扱うことによる圧力損失を減らします。流体の時間積分は2段のSSP-RK2です。

粘性・熱による壁面損失は、前版と同じ `sqrt(s)` の周波数依存性を持つ断面内分布の運動量緩和で近似しました。5個の因果フィルタを各セルに置き、125 Hz〜18 kHzで係数を合わせています。壁面の実際の粘性・熱境界層の厚さや乱流を解像するには別のモデルと格子が必要です。

## 唇・ベルの境界条件

唇はAdachi–Sato (1996)の前後・上下変位、閉鎖時の接触、唇が押しのける流れ、隙間を通る流れの慣性と抵抗を引き継ぎます。入口直内側の各リングから、管内から唇に届く音響特性量 `h_i = p_i - p0 - rho0*c0*u_i` を取り、その面積加重平均を `h` とします。入口で唇の総体積流量 `U_lip` とカップ音圧 `p_cup` を次の関係で同時に求めます。

```text
p_cup = h + (rho0*c0/S_cup) * U_lip
U_lip = 隙間の通過流量 + 唇運動による排除体積流量
```

求めた `p_cup` と隙間圧が次のステップの唇の運動方程式に入り、唇から管内に供給される流量が変わります。入口速度は面内で一様とし、局所境界圧は各リングの `h_i` を使います。境界での特性関係は小マッハ数の音響近似です。管内を往復する波は常に保存形Euler方程式で更新されます。

ベルでは平均モードに低周波の放射抵抗と端補正を合わせたRLインピーダンスを使います。他の半径方向成分は局所特性境界で流出させます。外部空間の放射域はモデル化せず、ベル全体の体積流量の時間微分から距離1 mの単極子放射圧を計算します。WAVには共通のゲインと48 kHzへのアンチエイリアス処理を適用します。各音高は演奏条件とモデルの発振から求めています。

## 実行

この実装ではCUDA対応NVIDIA GPU、対応するドライバ、CUDA NVRTCのライブラリを使います。WindowsではCUDAのNVRTCホイールまたはCUDA Toolkitを使用できます。12.4.127で動作を確認しました。Linuxでは実行時に `libnvrtc.so.12` を検索できるようにします。

```sh
python -m pip install -r requirements.txt
python -m pip install nvidia-cuda-nvrtc-cu12==12.4.127
python src/render_axisymmetric.py
python src/verify_axisymmetric.py
python src/verify_axisymmetric.py --coupling
python src/plot_axisymmetric.py
```

倍音解析と放射音への変換用に時系列を192 kHzで保存します。Euler方程式自体の時間刻みはCFLを基に計算しており、より短い刻みです。CUDAグラフを使って流体、唇、放射終端の更新をGPU上で続けます。

`data/performance_axisymmetric.json` に唇の自然周波数、静止開口、吹奏圧、必要な管長補正を保存しています。管長補正は既存のバルブ区間に円筒を追加する近似です。各音は一旦静止させてから発音します。

結果のフォルダは `output/axisymmetric` です。`measurements.json` に実際の音高と格子・時間刻み、`solver_tests.json` に衝撃波管・静止解・半径モードの検証、`coupling_tests.json` に唇の反射フィードバックの検証を保存します。`Bb4_field.npz` はベル内の断面方向の分布を確認するための瞬時場です。`*_coupled.npz` の列は入口圧、唇の総体積流量、唇x、唇y、通過流量、排除流量、吹奏圧、隙間圧、入口の平均戻り特性量 `h`、ベル体積流量、ベル平均音圧です。

RTX 2000 Ada Generationを使った演奏では、流体の刻み幅は約0.744 µsです。GPUに競合する計算がない区間では、0.72秒の1音を約13秒で計算しました。衝撃波管では軸方向200セルから400セルにすると圧力の平均絶対誤差が0.00243から0.00124に減り、400セルで衝撃波の位置差は約1.9 mmでした。円筒の第1半径方向モードは解析値3.947 kHzに対して約3.950 kHzになりました。

B♭4で入口への戻り特性量を唇の圧力式から外すと、持続発振が消えました。同じB♭4を細かい格子で再計算した検証では、音高が約7.9セント変わりました。演奏条件を用いた音高合わせの誤差と格子近似に由来する誤差は別の量です。

最後のB♭5は、持続中に約916 Hz（開始後0.24〜0.44秒）から約934 Hz（0.70〜0.94秒）に上がります。前半の発振の立ち上がり、音高変動も含めたWAVです。
