# BB♭コントラバス・チューバ

## 管体とマウスピース

Campbell、Gilbert、Myersの *The Science of Brass Instruments* 図7.46（本文365頁）から、Alexanderの16フィートC管コントラバス・チューバ（図7.45、エディンバラ大学楽器コレクション4283）の管径を読み取りました。その軸方向寸法を $2^{2/12}$ 倍してBB♭管に換算し、切れているベルの外側は図6.9（本文280頁）のフレアを拡大して接続しました。バルブ部の径20.5 mmとベル径450 mmには、Alexander 163の公称値を使っています。開放時の線形入力インピーダンスの共鳴間隔をBB♭管に合わせるため、組み合わせた管体の軸方向寸法をさらに0.936倍しました。マウスピースを含む開放時のモデル管長は5.532 mです。[書籍](https://doi.org/10.1007/978-3-030-55686-0) · [Alexander 163の公称寸法](https://gebr-alexander.de/products/b-oder-c-tuba-gebr-alexander-163m-messing-poliert-weite-bauart) · [校正前の管体半径曲線](../../data/alexander_bb_tuba_reconstructed.csv)

Yamaha BB-67C4は、VennCADの計測例から読み取ったカップ径32.54 mm、カップ深さ38.81 mm、スロート径8.05 mm、全長98.09 mmを基に再構成しました。カップ18.819 mLとバックボア4.064 mLの容積に合わせてテーパーを調整し、長さ4 mmの円筒スロートを仮定しています。計測例のカップ径をモデルの有効入口径とし、バックボア出口の径を管体受け口に合わせました。格子上の円錐台体積はカップ18.784 mL、バックボア4.075 mLです。[VennCADユーザーマニュアル（16頁）](https://www.vennture.mp/downloads/Documentation/VennCADHelp_v2-0-3.pdf) · [マウスピースの再構成曲線](../../data/yamaha_bb67c4_reconstructed.csv)

巻いた管を中心線に沿って展開した等価軸対称管として扱い、半径は形状保存三次補間（PCHIP）で結びます。第1〜4バルブはそれぞれ2、1、3、5半音を下げる公称ループとして扱います。バルブごとの付加長は、基準管長 $L_0=c/(2f_0)$ に対して $L_0(2^{s/12}-1)$ です。ここで $f_0$ はB♭0の周波数、$s$ は下げる半音数です。複数のバルブの付加長と音別の調律補正は円筒形のバルブ区間に加えます。開放時の標準格子は軸方向441区間、計2,422セルで、ベル開口を32の同心リングに分けます。

## 吹奏と放射

管内では粘性・熱損失を含め、軸対称の圧縮性Euler方程式を衝撃波捕獲型の有限体積法で時間積分します。Adachi–Satoの2自由度唇モデルで、マウスピースの圧力が唇を動かし、その開閉と変位が流入量に反映されます。ベルでは開口速度の4つの軸対称モードを等価球の外部音場に接続します。放射負荷による反射は管内へ戻り、出力WAVにはベル正面1 mで得られる圧力波形を使います。[唇モデル](https://doi.org/10.1121/1.414601) · [流体ソルバー](AXISYMMETRIC_MODEL.md) · [ベル放射モデル](../trumpet_bell_exterior.md)

音階は実音B♭1〜B♭4のB♭メジャー上行22音です。収録した強いアタックの設定では、吹奏圧を6.5 msで立ち上げ、立ち上がり時の圧力を持続圧より45%上げてから28 msで持続圧に戻します。各音の吹奏圧、唇の固有振動数、運指、管長補正は演奏設定に記録しています。最後のB♭4は1.65秒、ほかの各音は1.08秒で、各音の後に90 msの間隔が入ります。WAVは26.31秒、48 kHz、16 bit、モノラルです。[演奏設定](../../data/performance_tuba.json)

## 再生成

リポジトリのルートからCUDA環境で実行します。

```sh
python src/render_tuba_scale.py
```

`output/tuba_axisymmetric/` に `BBb_tuba_Bb1_Bb4_major_f_strong_attack.wav` と `measurements.json` を書き出します。測定JSONには各音の周波数、目標音からの偏差、放射音圧、格子と時間刻みが入ります。短い試算は、たとえば `python src/render_tuba_scale.py --only Bb1 Bb4 --probe 0.45` で実行できます。
