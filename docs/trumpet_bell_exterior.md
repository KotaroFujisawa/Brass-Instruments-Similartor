# トランペットのベル外部放射とテーパーの細分化

実音B♭4、B♭5、B♭6をフォルテで計算する。各音0.80秒で、吹奏圧と唇の設定は直前の強いアタック版から取得する。各音について従来の格子と放射、細分化した格子と従来の放射、細分化した格子と新しい放射の3条件を比較する。

## 管の形状

York製B♭トランペットの管径は、Campbell、Gilbert、Myersの図7.52から取得済みの点を使う。管体の半径を形状保存三次補間（PCHIP）で結び、リードパイプとベルの主要なテーパーでは軸方向を最大2.4 mm、最後の110 mmを最大1.6 mm、先端28 mmを最大1.3 mmに分割する。開放・管長補正なしでは軸方向406列から542列、全体1,086セルから1,538セルとなる。ベル面は16リングで、マウスピースのカップ・スロート・バックボアの接続も保持する。元の図の計測精度は、補間や格子の細分化では向上しない。[The Science of Brass Instruments](https://doi.org/10.1007/978-3-030-55686-0)

## ベル面での双方向連成

ベル面の軸方向流速を断面積で直交する4モードに射影する。軸対称の外部領域は、ベル半径を半径とする等価球の外側とする。前半球に開口の流れを投影し、後半球は剛体とする。球面の法線速度を `u_n = u_z cos(theta)` とすることで、投影した開口面と球面の間で体積流量と音響仕事を対応させる。

外部の線形音響を外向き球面波で解き、球面調和次数0から10までを残す。各次数の放射インピーダンスを組み合わせて、開口4モードの反射行列を得る。これを66状態の因果的な系に変換し、CUDAの各時刻で進行波から戻り波を求める。開口の各リングに戻り波を展開し、境界圧と速度を圧縮性Eulerの流束に反映する。4モードから外れた成分には外向き特性境界を適用する。

正面0°、斜め45°の放射圧は同じ外部解から、等価球の中心から1 mで求める。試聴用WAVは共通の伝搬遅延を除き、すべての条件と角度に同じ出力ゲインを用いる。外部は線形、幾何は等価球近似で、実際のベル外壁の形と放射指向性の実測を使った校正が今後の課題になる。元の有限体積ソルバーが管内の非線形伝搬を解く。[球外波動方程式の解](https://arxiv.org/abs/1308.0643) · [金管楽器の軸対称外部音場](https://doi.org/10.1051/aacus/2025049) · [ベル放射のモデルと計測の比較](https://dael.euracoustics.org/bin/EAA/aaua_dl?document_id=65167)

## 再生成

```sh
python src/render_trumpet_bell.py
python src/plot_trumpet_taper.py
python src/verify_trumpet_bell.py
python src/verify_bell_exterior.py --output output/trumpet_bell/bell_exterior_verification.json
```

`output/trumpet_bell/` にWAV、倍音スペクトル、音程とカップ内の音圧、テーパーの図、各音の測定値が出る。CUDAの検証では、弱いパルスを与え、各リングの実流速から周波数領域で再構成したベル圧力をGPUの出力と比較する。
